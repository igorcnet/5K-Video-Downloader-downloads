## Na primeira vez que abrir

O programa ainda não tem assinatura digital, então o sistema mostra um aviso antes de abrir pela primeira vez:

- **Windows**: na tela "O Windows protegeu o computador", clique em **Mais informações** e depois em
  **Executar assim mesmo**.
- **Mac**: arraste o 5K Video Downloader para Aplicativos e abra. Se o Mac disser que não pode verificar o app,
  vá em **Ajustes do Sistema → Privacidade e Segurança** e clique em **Abrir Mesmo Assim** (no macOS 14 ou
  anterior: botão direito no app → **Abrir**).

Este repositório guarda só os instaladores, publicados automaticamente a cada versão. O programa leva o FFmpeg
(GPL), o Deno (MIT) e outras bibliotecas; os avisos de licença ficam na pasta `licencas` dentro do programa.

Use o programa apenas para baixar conteúdo que você tem o direito de baixar.
